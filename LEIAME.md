# Olho em Python turtle

Só o código que desenha o olho, sem nada da produção do vídeo.

- `olho.py`: versão em português
- `eye.py`: versão em inglês (mesmo desenho, nomes e comentários em inglês)

## Como rodar

```bash
python3 olho.py
```

Abre uma janela, desenha o olho (contorno, íris, pupila, reflexo e cílios) e depois ele fica piscando a cada 2 segundos. Para parar, é só fechar a janela.

Não precisa instalar nada: o `turtle` já vem com o Python. A única exceção é o Linux, onde às vezes falta o Tkinter (`sudo apt install python3-tk`).

O desenho da íris tem milhares de traços, então leva um tempinho para aparecer inteiro na janela.
